Hi! I've split the files for this project and here's an explanation of all of them :)
1) angus-vision: this is a folder with sketch.js and index.html. The sketch.js is able to be pasted into p5.js to connect to the arduino installed inside Angus. Here's a link to the sketch on p5: [p5 Angus Vision](https://editor.p5js.org/joyce_kung/full/3BYMfDU1C”)
2) angus_lasercut.ai: this is the Illustrator file that I used to laser cut the wood parts for Angus. I used the box generator [boxes.py](https://boxes.hackerspace-bamberg.de/") to create it initially and edited it to make room for details like Angus' tuft of hair.
3) angus_model.f3d: this is the 3D model I used to lay out and 3D print from when making Angus.
4) expressive_platypus.ino: this is the arduino .ino file uploaded onto the Arduino Minima that's installed in Angus' internals.
